# MachineObserver V0.7 — Architecture Freeze

V0.7 is the consolidated build after the V0.6.1 proof-of-concept phase.

## Pipeline

Process Sensor + Network Sensor + DNS Graph
-> Correlator
-> Temporal Activity Engine
-> SQLite Evidence Store
-> Reasoner
-> Human Meaning

## Components

1. Process Sensor — PID, name, executable, command line, create time, process-instance ID.
2. Network Sensor — protocol, local/remote endpoints, first/last observed, BASELINE, OBSERVED_NEW, DISAPPEARED.
3. DNS Graph — hostname, CNAME, A, AAAA, TTL, first/last seen, expiry.
4. Correlator — Process Instance OWNS_FLOW TCP flow; DNS_RESOLVED_TO links hostname and address.
5. PTR Context — context only; never identity proof.
6. Active Probes — optional and OFF by default; TLS/HTTP; always PROBED; observer-owned traffic excluded from ordinary observed evidence.
7. Reachability Model — DNS_RESOLVED, TCP_CONNECTED, TLS_ESTABLISHED, HTTP_RESPONDED, HTTP_STATUS. HTTP 403 is an HTTP response, not a network failure.
8. Temporal Activity Engine — process + hostname + time window + evidence IDs + activity boundaries.
9. Evidence Classes — OBSERVED, CORRELATED, CONTEXT, PROBED, INFERRED, UNKNOWN.
10. SQLite Evidence Store — sessions, process_instances, flows, dns_records, flow_dns_links, ptr_context, probes, activities.
11. Reasoner — WHAT, WHO, WHEN, proof, inference and unknowns.

## Probe isolation invariant

MachineObserver's own active probes must never contaminate the passive evidence stream.

Probe-generated traffic is labelled PROBED and the observer process instance/PID is excluded from ordinary process/network activity interpretation.

## Attribution boundary

Ordinary process/TCP/DNS telemetry can attribute a connection to a browser process and may correlate it with a hostname. It cannot truthfully identify the exact browser tab or HTTPS URL/path.

Tab-level attribution requires a browser-side sensor. HTTPS content remains unavailable unless legitimately instrumented at an endpoint.
